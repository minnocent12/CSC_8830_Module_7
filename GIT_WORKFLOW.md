# GIT_WORKFLOW.md — Module 7

The canonical Git/GitHub protocol is `../GIT_WORKFLOW.md`. This module follows it in full.

Module 7 is intended to become its own repository, with one task branch per approved phase.
Until repository topology is explicitly established, do not run `git init` here and do not
copy another module's `.git` directory. Do not commit, push, force-push, reset, delete
branches, or rewrite history without explicit authorization.

Governance, planning, and assignment-source files may remain local-only if the eventual
Module 7 repository adopts the same `.git/info/exclude` convention used by Modules 2–6.
The final policy must be recorded in the module repository before any public deployment sync.
